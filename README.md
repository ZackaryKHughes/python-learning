# Budget Tracker App

A Python budget tracker built while learning Python programming.

Features:
- Income tracking
- Expense tracking
- Savings goals
- Emergency fund tracking
- Investment tracking
- Balance persistence between months
- File handling
- Dictionaries and lists

## Features

- Add income records
- Add expense records
- Track month and year
- Normalize month names like Jan, january, JAN
- Calculate total income
- Calculate total expenses
- Calculate checking balance
- Transfer money to savings, emergency fund, and investments
- Save balances for future use

## Files

- `budget_calculator.py` - Main program
- `budget_functions.py` - Helper functions
- `balances.txt` - Local saved balances, ignored by Git

## How to Run

```bash
python3 savings_goal.py
